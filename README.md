LYRICLICKER
Für den lyriclicker muss man es so screiben:
python3 lyriclicker.py faint.txt
faint.txt sind die lyrics und können auch ersetzt werden
---
MATRIX
Für den matrix muss man es einf so runnen:
python3 matrix.py
Mann muss aber zuerst den spacebar drücken und dann enter vor mann schreiben kann.
